# SiteMills Scoop Bucket

```powershell
scoop bucket add sitemills https://github.com/SiteMills/scoop-bucket
scoop install sitemills-cli
```

Upgrade with `scoop update sitemills-cli`. See the [SiteMills CLI](https://github.com/SiteMills/sitemills-cli) for documentation and other install options.

**Do not commit to this repository directly.** `bucket/sitemills-cli.json` is generated and published by the SiteMills CLI release tool on every release.
